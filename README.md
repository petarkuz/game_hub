# GameHub

A React and TypeScript application for discovering and exploring video games using data from the RAWG Video Games Database API.

The project was built to strengthen practical frontend development skills including component-based architecture, API integration, custom hooks, state management, filtering, sorting, and responsive user interface design.

---

## Features

* Browse and discover video games
* Search games by title
* Filter by genre
* Filter by platform
* Sort results using multiple criteria
* View game ratings and metadata
* Responsive user interface
* Dynamic API-driven content
* Reusable React components

## Setup & Installation

## Clone Repository

```bash
git clone https://github.com/petarkuz/game_hub.git
cd game_hub
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Application runs locally on:

```text
http://localhost:5173
```
